# 行迹 · GPX 卫星轨迹查看器（PWA）

纯静态网页，无需构建。GPX 只在本机解析，存进浏览器 IndexedDB，不上传任何服务器。

## 文件
- `index.html` / `style.css` / `app.js`：应用本体（地图用 Leaflet 1.9.4）
- `sw.js`：离线缓存 + 接收「分享到行迹」的 GPX
- `manifest.webmanifest`、`icons/`：安装到主屏幕用

## 本地运行（电脑）
```
python -m http.server 8765 --directory gpx-map
```
浏览器打开 http://localhost:8765 。Chrome / Edge 可以点地址栏的「安装」图标装成桌面应用。

## 手机上用
PWA 需要 https。把 `gpx-map` 文件夹整个放到任意静态托管（GitHub Pages、Cloudflare Pages、Netlify 拖拽上传都行），
手机 Chrome 打开后 菜单 →「添加到主屏幕 / 安装应用」。

临时测试（手机 USB 连电脑）：`adb reverse tcp:8765 tcp:8765`，然后手机 Chrome 打开 http://localhost:8765 。

## 导入
- **选择文件夹**：电脑 Chrome/Edge 和安卓 Chrome 都会记住这个文件夹，之后点「同步」一键导入新轨迹（已授权时打开应用会自动同步）。
- **文件**：多选 GPX 文件。
- 安卓安装后，在两步路 / 六只脚里「分享 → 行迹」也能直接导入；电脑上安装后可以用「打开方式」打开 .gpx 文件。
- 同一条轨迹从不同 App 导出时按几何形状自动去重；空轨迹会自动跳过；`xxx.gpx (1)` 这种被改过名的文件也能识别。

## 操作
- 轻点地图空白处：隐藏 / 显示所有按钮（纯净看图）。电脑上按 `H` 隐藏、`F` 回到轨迹、`Esc` 关闭面板。
- 右下角：轨迹库 / 图源 / 回到轨迹。
- 轨迹库：最近一条 / 已选 / 全部（可按年份筛选），顶部显示累计里程、在路上的小时数、出行天数。
- 单条轨迹：按速度渐变着色（色带上限随这条轨迹的最高速自动调整），下方是速度曲线（实线）+ 海拔（虚线），手指在曲线上拖动可在地图上定位；「回放」会动画重走一遍。

## 图源
谷歌卫星、谷歌卫星+路网、Esri、Bing、高德卫星（GCJ-02）、谷歌街道，地图最大可放大到 22 级
（超过图源原生级别后会放大显示）。可以在图源面板里添加自定义 URL，支持 `{x} {y} {z} {s} {q}(Bing quadkey) {-y}`。
谷歌 / Bing / 高德是非官方瓦片地址，个人自用，可能随时失效；Esri 最稳定。

## 坐标系
默认 GPX 是 WGS-84（GPS 原始坐标）。切到高德图源时会自动把轨迹转成 GCJ-02 对齐；如果你的 GPX 本身是火星坐标，在「设置 → GPX 坐标系」里改成 GCJ-02。国外的轨迹不受影响。
